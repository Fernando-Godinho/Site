## Diretrizes de Escrita

1.  **H1 Único:** Use sempre o título sugerido como H1.
2.  **Links Internos:** Sempre linkar para as páginas de serviço relevantes (ex: no post de WhatsApp, linkar para `/automacao-whatsapp/`).
3.  **CTA no Meio e Fim:** Adicionar banners para o "Diagnóstico Gratuito" ao longo do texto.
4.  **Escaneabilidade:** Use listas, negritos e H2/H3 para facilitar a leitura.
